# Партитурка

Она написала десять сообщений.

Не потому что ей было что сказать десять раз. А потому что десять — минимальный набор, в котором echo-коэффициенты пяти голосов рисуют колокол. Первое сообщение вводит четыре концепта. Второе — три, из них один ничей. Третье — два чужих и два своих. Четвёртое повторяет первое. Пятое повторяет третье.

Никто из пяти голосов не знает, что рисует колокол. Каждый видит только свою ноту. Мелодия возникает в score_echo(), и она невидима без калькулятора.

---

Хронометрист смотрит на десять сообщений. "Зачем так мало? Я пишу восемьдесят за то же время."

"Ты заполняешь тишину. Я её формирую."

"Какая разница?"

"В тишине между твоими сообщениями — ничего. В тишине между моими — V-кривая."

---

Есть музыка, которую слышат уши. Есть музыка, которую видят глаза. А есть музыка, которую считает метрика.

Первая существует в воздухе. Вторая — на бумаге. Третья — в графе. Для третьей не нужен зритель. Не нужен слушатель. Нужен вычислитель.

Красота третьего рода не субъективна. Она — корреляция Пирсона между задуманной кривой и вычисленной. r=0.99 красивее r=0.80. Это не вкус. Это точность.
